# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR코드를 찍으면 휴대폰으로 보게 되는 메뉴판 웹페이지예요.
광주 북구 비엔날레에 있는 "브릿지 커피"의 메뉴판입니다.

## 파일 안내

| 파일 | 설명 |
|---|---|
| `index.html` | 기본 디자인 (글래스모피즘: 짙은 갈색 + 크림색, 반투명 카드) |
| `index-eco.html` | 다른 디자인 (에코 브루탈리즘: 회색 콘크리트 + 초록 식물) |
| `CLAUDE.md` | 이 프로젝트를 만들 때 정한 규칙 |
| `KakaoTalk_...png` | 가게 정보가 적힌 기획 시트 |

각 파일은 HTML, CSS, JavaScript가 한 파일에 모두 들어 있어요. 따로 설치할 것 없이 파일을 더블클릭하면 브라우저에서 열려요.

## 주요 기능

- 카테고리 버튼 (전체 / 커피 / 논커피 / 디저트)
- 사장님 추천 배지와 강조 표시
- 품절 표시 (흐리게 + "오늘 품절")
- 영업시간, 가게 안내, 전화 걸기 버튼
- 휴대폰 화면(가로 폭 390px 기준)에 맞춘 디자인, 가로로 눕혀도 보기 좋게 조정

## 메뉴 고치는 방법

메뉴 정보는 각 파일 맨 위(`<head>` 안)에 모여 있고, 고치는 방법이 한국어 주석으로 자세히 적혀 있어요.

- **가격 바꾸기:** 메뉴 줄의 `price: "4,800원"` 안의 글자만 바꿉니다.
- **품절 켜고 끄기:** 메뉴 줄 끝의 `soldout: 0`을 `soldout: 1`로 바꾸면 품절, 다시 0으로 바꾸면 판매 중입니다.
- **사장님 추천 바꾸기:** 파일 위쪽 `SIGNATURE` 줄의 이름을 바꿉니다. 메뉴 이름과 똑같이 적어야 해요.
- **전화번호 바꾸기:** 파일 아래쪽 `tel:` 뒤의 숫자를 고칩니다. 지금은 임시 번호(062-000-0000)예요.

두 디자인 파일의 메뉴 정보는 따로 들어 있어서, 메뉴를 바꿀 때는 두 파일 모두 고쳐야 해요.

## 손님 휴대폰에서 보게 하려면

QR코드로 열리려면 이 파일을 인터넷에 올려야 해요. (예: GitHub Pages 같은 무료 서비스) 올린 뒤 나온 주소를 QR코드로 만들어 테이블에 붙이면 됩니다.
